Helios Core is a major update to the cross-platform voice AI assistant, introducing digital autonomy by allowing users to choose their own engine stack (local or API-based) and fall back to local models when Gemini quotas run out. Key performance and UX improvements include Whisper/Piper support for offline, multilingual conversation with real-time speed, reasoning model output filtering, and tool command execution that verifies outcomes rather than assuming success. The update also adds device-specific volume control, an audio diagnostic panel, and a phone dashboard with improved security, while deferring heavy imports to eliminate startup costs when features are unused.
